# Illumine Classroom Prototype

[Open the demo](https://vedantproductmanager.github.io/illumine-classroom-prototype/) · [Read the product note and research](PRD.md)

A mobile-first classroom prototype for nap checks, group activity sharing, and meal tracking. The sign-in fields are prefilled. Open **Chandler Reed** to see sample care information, activity posts, and seven-day nap and meal records.

The demo uses fictional data and simulated family delivery. Changes reset when you reload. To run it locally, keep the files together and open `index.html` in a browser.
